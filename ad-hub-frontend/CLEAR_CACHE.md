# Решение проблемы с кешированием при смене порта

Если при запуске на другом порту сайт работает "как до исправлений", это означает, что браузер использует закешированную старую версию файлов.

## Быстрое решение

### 1. Очистка кеша браузера (рекомендуется)

**Chrome/Edge:**
- Нажмите `Ctrl + Shift + Delete`
- Выберите "Изображения и файлы в кеше"
- Выберите "За все время"
- Нажмите "Удалить данные"

**Firefox:**
- Нажмите `Ctrl + Shift + Delete`
- Выберите "Кеш"
- Выберите "Все"
- Нажмите "Очистить сейчас"

**Или используйте жесткую перезагрузку:**
- `Ctrl + Shift + R` (Windows/Linux)
- `Cmd + Shift + R` (Mac)

### 2. Очистка кеша для конкретного сайта

1. Откройте DevTools (`F12`)
2. Правой кнопкой мыши на кнопку обновления
3. Выберите "Очистить кеш и жесткая перезагрузка"

### 3. Режим инкогнито

Откройте сайт в режиме инкогнито (`Ctrl + Shift + N`), чтобы проверить без кеша.

## Долгосрочное решение

Конфигурация Vite обновлена для предотвращения кеширования в режиме разработки. После перезапуска dev-сервера изменения должны применяться автоматически.

## Если проблема сохраняется

1. Остановите dev-сервер (`Ctrl + C`)
2. Удалите папку `node_modules/.vite` (если существует)
3. Перезапустите dev-сервер: `npm run dev`
